
# SkillForge - Landing Page

SkillForge is a modern and responsive online learning platform landing page created as part of the Oasis Infobyte Web Development & Designing Internship.

## Project Overview

The SkillForge landing page is designed to provide students with a simple and attractive platform for discovering online courses and learning opportunities.

## Features

- Sticky navigation bar
- Responsive hero section
- Course listing section
- Features section
- About section
- Testimonials section
- Call-to-action section
- Contact and enquiry form
- Responsive design for desktop, tablet, and mobile
- CSS hover effects and animations
- Responsive navigation links
- Clean and consistent UI design

## Courses

The landing page includes:

- Web Development
- Java Programming
- Python Programming
- Data Analytics
- Machine Learning
- UI/UX Design

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS Media Queries
- CSS Animations
